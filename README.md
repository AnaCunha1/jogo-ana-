# Cyber Jumper - Missão Neon

Jogo 2D de plataforma desenvolvido em HTML5 Canvas, CSS3 e JavaScript puro.

## Diferenciais
- **Pulo Duplo:** Sistema de propulsor que permite pular duas vezes no ar com partículas animadas.
- **Estilo Cyber-Neon:** Cenário espacial animado com cristais flutuantes, lasers e drones de patrulha.

## Controles
- **A / D** ou **Setas:** Movimentar o personagem.
- **Espaço / W / Seta para cima:** Pular (pressione duas vezes para pulo duplo).
